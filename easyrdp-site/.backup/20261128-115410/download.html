SHA256 校验说明

上方卡片中的 SHA256 来自 SHA256SUMS.txt（随每次发布自动更新）。下载后请计算本地文件的 SHA256 并与卡片值比对，一致方可使用。

Windows（PowerShell）

Get-FileHash .\EasyRDP-0.4.2-win32-x64-portable.zip -Algorithm SHA256

macOS / Linux

sha256sum EasyRDP-0.6.2-portable.exe
shasum -a 256 EasyRDP-src-0.4.2.tar.gz   # macOS
校验值不一致时请勿运行安装包：可能传输不完整或文件被篡改。请重新下载或到 GitHub Releases 反馈。
