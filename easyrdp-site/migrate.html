迁移概览

EasyRDP 基于 Rust + Tauri 2 + FreeRDP 构建，兼容导入 mstsc（Windows 自带「远程桌面连接」）生成的标准 .rdp 文件，也支持把现有连接导出回 .rdp 与 Windows 自带客户端双向互通。配合 JSON Profile 导入导出、标签页多会话并行与剪贴板双向同步（文本 + 文件），绝大多数迁移场景无需逐条手工录入。

原工具EasyRDP 导入方式凭据是否迁移
mstsc（Windows 远程桌面）直接导入 .rdp 文件（文件选择框 / 拖入 / CLI，字段自动映射）主机/端口/用户名/分辨率/重定向开关；密码不迁移
RemminaRemmina 连接可逐条对照字段手工新建；若有对应 .rdp 源文件则直接导入主机/端口/用户名，密码不迁移
Royal TS先用 Royal TS 的 .rdp 导出功能导出标准 .rdp，再用 EasyRDP 导入主机/端口/用户名，密码不迁移
向日葵 / ToDesk 等国内远控无 .rdp 可导出，按主机信息在 EasyRDP「新建连接」中录入（目标机需开启 Windows 远程桌面）主机/端口/用户名，密码不迁移

导入后每条连接即一份 JSON Profile（存于本机用户配置目录，可纳入 Git 管理），Ctrl+K 全局搜索可在多台主机间极速切换。首次连接时输入一次密码即可；如需批量搬运连接，还可用 JSON Profile 整体导入导出。

一、.rdp 文件导入（会话/连接配置迁移）

如果你一直在用 mstsc 连接服务器或同事的电脑，那么这些连接大多已保存为 .rdp 文件（mstsc 中「另存为」即可生成，默认保存在「文档」目录）。EasyRDP 提供三种导入方式：

方式 A：图形界面导入（推荐）

  1. 打开导入入口：启动 EasyRDP，在「新建连接 / 导入」面板中点击文件选择框（系统文件选择对话框）。
  2. 选取 .rdp 文件：选中 mstsc 导出的 .rdp 文件（可一次选取多个逐个导入）。
  3. 确认字段映射：导入时字段自动映射为 EasyRDP 的 JSON Profile（见下方映射表），无需手动输入。
  4. 补录凭据：首次连接该主机时输入密码即可开始使用。

方式 B：拖入连接中心

把 .rdp 文件直接拖入连接中心窗口，即完成导入——字段自动映射，与方式 A 等效。

方式 C：命令行批量导入（linkdesk CLI）

# 单文件导入：将 mstsc .rdp 文件导入为 JSON Profile
linkdesk import office.rdp

# 批量导入当前目录全部 .rdp 文件（--overwrite 覆盖同名 Profile）
linkdesk import ./*.rdp --overwrite

# 导出 .rdp，交还给 Windows 自带客户端使用
linkdesk export office-win11 -o office-win11.rdp

.rdp 字段映射（节选）

.rdp 字段JSON Profile 字段说明
full address:shost + porthost:port 自动拆分，缺省端口 3389
username:sauth.username用户名；密码不随 .rdp 迁移
desktopwidth / desktopheightsession.resolution初始分辨率
redirectclipboard:iredirection.clipboard剪贴板重定向
drivestoredirect:sredirection.drive驱动器重定向
redirectprinters:iredirection.printer打印机重定向
🟢 双向互通：导入只是单向的第一步——EasyRDP 也能把现有连接导出为标准 .rdp，同事仍在用 mstsc 时零成本互换。
⚠️ .rdp 文件中的 password 51:b: 加密块仅在生成它的 Windows 本机有效，EasyRDP 导入时不会导入密码，需在连接时重新输入。

二、凭据与安全说明

  • 密码仅存本机，不上传：v0.4.2 中密码仅保存在本机用户配置目录，不上传任何服务器；后续版本将切换为系统凭据库（DPAPI / Keychain / libsecret）加密存储，Profile 中仅保留加密条目引用（见 FAQ）。
  • JSON Profile 导入导出：每条连接对应一份 JSON Profile，字段化、可版本化，可纳入 Git 管理与代码评审；团队可共用 Profile 模板批量下发，实现「配置即代码」。规范见 文档 · JSON Profile。
  • 不要把明文配置带进公开仓库：Profile 当前以明文保存凭据相关字段（用户名），密码按上述规则仅留本机；把配置目录同步到网盘 / Git 私有仓库前，请先确认其中不含敏感信息。
  • 绿色便携、不写注册表：EasyRDP 为单文件绿色版，不写注册表、不装驱动、不驻留服务端组件，删掉文件即完全卸载——迁移前后的机器环境保持干净。
  • 下载校验：安装包请从下载页获取并按 SHA256 校验说明比对哈希后再运行。
💡 给从 mstsc 迁移的用户：mstsc 默认勾选「允许我保存凭据」会把密码交给 Windows 凭据管理器；EasyRDP 的凭据存放位置独立且可随 Profile 审计，切换后请按需清理旧的系统保存凭据。

三、常见迁移场景对照表

你原来的用法EasyRDP 对应能力迁移要点
mstsc 连接历史（「最近使用」里攒了一批主机，逐个重新输入地址） 把历史连接另存为 .rdp 后批量导入；Ctrl+K 全局搜索直达任意主机 卡片式连接中心集中管理所有主机，一劳永逸
多会话 / 多窗口（开多个 mstsc 窗口来回切） 标签页多会话并行：主界面保持可见，多远程桌面窗口并存，活跃会话数显示与逐会话快捷断开 不再需要任务栏里翻找多个 mstsc 窗口
剪贴板复制粘贴（mstsc 仅文本，文件要走驱动器映射） 剪贴板双向同步：文本 + 文件。本地复制文件远端直接粘贴；远端复制文件自动落地到「下载\EasyRDP-Clipboard\」并写入本地剪贴板 单次 ≤128 个文件、单文件 ≤2GiB；远端 rdpclip 未就绪时底部会提示引导重启
组合键发送（Ctrl+Alt+Del 在远程桌面里无法直接送达） 标题栏 SAS 槽下拉菜单：发送 Ctrl+Alt+Del（SAS）/ Win 键 / Win+D / Win+E / Win+R / Win+L / Ctrl+Shift+Esc（任务管理器）/ Alt+Tab；也可在本地按 Ctrl+Alt+End 热键发送 SAS；设置中心「⌨ 组合键」支持自定义组合键，对所有会话生效 锁屏、改密码、开任务管理器不再需要本地中转
全屏 / 自适应分辨率（每次改窗口大小要手动调分辨率） desktopwidth / desktopheight 导入为 session.resolution；会话支持多显示器与色彩深度配置，FreeRDP 协议栈按窗口自适应 .rdp 里的分辨率偏好原样保留，导入即生效

四、从其他 RDP 工具迁移的注意事项

  • FreeRDP 全静态链接，无需安装服务端组件：EasyRDP 的 Windows 单文件版为全静态链接构建（无 DLL 依赖），双击即用；客户端侧不安装任何服务、驱动或常驻组件，卸载即删文件夹。
  • 仅依赖 WebView2 Runtime（Win10/11 通常已内置；缺失时运行时会提示自动安装）。
  • 协议能力来自标准 RDP：RDP 8+ 压缩、多显示器、剪贴板与驱动器/打印机重定向均基于 FreeRDP 协议栈实现，与 mstsc 连接同一台目标机无需在服务端做任何额外配置。
  • 连接前先测连通：v0.4.2 支持连接前 TCP 连通性测试（一键检测主机可达与端口响应并显示延迟），迁移首批主机时建议逐条测试，快速定位地址或端口写错的情况。
  • 从向日葵 / ToDesk 迁移：国内远控走私有协议，不受 Windows 远程桌面限制；换成 EasyRDP 后走标准 RDP，请确认目标机已开启「远程桌面」（系统设置 → 远程桌面），且账号具备远程登录权限、防火墙放行 3389 端口。
  • 网关接入（规划中）：JSON Profile 已预留 gateway 字段，云网关与策略矩阵（细粒度管控剪贴板/驱动器/USB/打印机重定向）为后续版本路线图，详见 功能页。

五、常见迁移问题 FAQ

Q1：导入 .rdp 后为什么要求重新输入密码？

.rdp 中 password 51:b: 加密块只在生成它的那台 Windows 本机有效（绑定 DPAPI），EasyRDP 导入时不会导入密码，也从不迁移、上传任何密码。首次连接输入一次即可，密码仅存本机。

Q2：导入后连接失败，如何排查？

先在连接上执行「测试连通」做 TCP 握手：不通多半是地址/端口错误、目标机未开启远程桌面或防火墙未放行 3389；通而会话异常则检查账号是否具备远程登录权限。可对照导入的字段映射表确认 host:port 拆分是否正确。

Q3：文件剪贴板传输有没有限制？

单次 ≤128 个文件、单文件 ≤2GiB，目录以空目录语义传递；传输走 CLIPRDR FileContents 标准协议，仅传描述符与内容流（路径不出网线）。远端→本地的文件自动落地到「下载\EasyRDP-Clipboard\」。

Q4：粘贴文件没反应？

远端会话的 rdpclip 剪贴板服务可能停摆——任何客户端此时都会失效。EasyRDP 在连接 10 秒未收到剪贴板就绪信号时会在底部提示「远端剪贴板服务未就绪（rdpclip 未响应）」，按提示重启远端 rdpclip 即可。

Q5：向日葵 / ToDesk 能连的主机，EasyRDP 一定连得上吗？

不一定。国内远控不依赖 Windows 远程桌面，而 EasyRDP 走标准 RDP：目标机必须开启远程桌面并放行 3389。家用版 Windows 通常只允许单会话登录，且远控账号若非本地管理员组成员，需先加入「Remote Desktop Users」。

Q6：怎么把所有连接整体搬去另一台电脑？

用 JSON Profile 导入导出：Profile 为纯 JSON 文件，可直接拷贝配置目录或纳入 Git 同步；批量场景用 linkdesk import / export 脚本化搬运。详见 文档 · CLI 用法。
