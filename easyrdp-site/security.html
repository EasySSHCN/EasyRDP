安全策略

我们高度重视 EasyRDP 及其用户的安全。发现漏洞请通过本页渠道私密报告，切勿公开披露。

🔒 漏洞报告

如发现安全漏洞（凭据泄露、协议实现缺陷、内存安全、供应链风险等），请发送邮件至：

security@easyrdp.cn （占位邮箱，正式启用前以仓库 SECURITY.md 为准）

报告请尽量包含：

  • 漏洞类型与影响评估（可否远程利用、影响版本）
  • 详细复现步骤或 PoC
  • 相关平台（Windows / macOS / Linux）与版本号
响应承诺：我们将在 3 个工作日内确认收到报告，并在 30 天内给出评估与修复计划。 修复发布前，请勿公开披露细节。我们会在安全公告中致谢报告者（可要求匿名）。

🛡 安全基线

领域措施
传输加密强制 TLS 1.2+，禁用弱加密套件；优先 NLA 网络级认证
凭据存储Windows DPAPI / macOS Keychain / Linux libsecret，Profile 不落明文
编译期缓解启用 CFG（控制流防护）、ASLR（地址空间随机化）、DEP
数据收集无遥测、无埋点，网络行为仅为 RDP 会话本身
供应链发布物附带 SHA256 校验文件；依赖锁定与 CI 可重复构建
