功能介绍

六大功能域覆盖个人与企业的远程桌面全场景：F1–F3 已在 v0.1.0-alpha 落地，F4–F6 列入路线图。

🗂

F1 · 连接中心

连接中心是 EasyRDP 的主界面：所有远程主机以卡片形式呈现，支持按名称 / 标签 / 最近使用排序与分组； 每个远程会话运行在独立标签页中，多会话并行不互相干扰； 全局搜索 Ctrl+K 让你在上百台主机中瞬时定位目标连接，支持模糊匹配主机名、备注与标签。

  • 卡片式连接管理：分组、收藏、置顶
  • 标签页多会话：并行会话 + 快速切换
  • Ctrl+K 全局搜索：主机名 / 备注 / 标签模糊匹配
📄

F2 · 新建连接与 .rdp 兼容

新建连接向导覆盖主机、端口、凭据、分辨率与重定向选项；同时完整兼容 mstsc 生成的 .rdp 文件——拖入即导入，字段自动映射为 EasyRDP 的 JSON Profile， 也可以把现有连接导出为 .rdp 交还给 Windows 自带客户端使用，零迁移成本。

  • 新建连接向导：主机 / 端口 / 认证 / 重定向一步到位
  • 导入 mstsc .rdp 文件（full address、username、redirect* 等字段）
  • 导出标准 .rdp，与系统远程桌面双向互通
🖥

F3 · 远程会话

会话层基于 FreeRDP 协议栈：支持 RDP 8+ 远程压缩、自适应分辨率与多显示器、 剪贴板 / 驱动器 / 打印机重定向。连接断开后可快速重连恢复会话，网络抖动时自动降级画质保流畅。

  • 多显示器与自适应分辨率
  • 剪贴板 / 驱动器 / 打印机重定向开关
  • 断线自动重连与画质自适应
🛡

F4 · 网关接入 路线图 · V1

面向复杂企业网络的自有云网关：客户端仅出站访问网关 443 端口， 内部通过 TLS 隧道转发 RDP 流量；接入需先通过预认证，再叠加 OTP 动态口令二次验证， 无需暴露任何内网主机的 3389 端口。

  • 443 端口 TLS 隧道（复用 HTTPS 通道）
  • 预认证 + OTP 二次验证
  • 网关侧主机映射与最小权限访问
🏢

F5 · 管理控制台 路线图 · V2

企业管理员控制台：对接 SSO / OIDC 完成统一身份认证与 MFA 强制策略； 以策略矩阵细粒度管控设备重定向（剪贴板 / 驱动器 / USB / 打印机）； 支持会话水印、按需录制与完整审计日志，满足等保与内控合规要求。

  • SSO / OIDC + MFA 统一认证
  • 设备重定向策略矩阵（按用户 / 主机 / 时段）
  • 会话水印、录制与审计日志
🧩

F6 · 配置即代码

每条连接即一份 JSON Profile，可纳入 Git 管理与代码评审； 团队可共用 Profile 模板批量下发；兼容导入 mstsc .rdp，也可导出回 .rdp， 实现传统工具与基础设施即代码（IaC）工作流的无缝衔接。

  • JSON Profile：字段化、可版本化、可模板化
  • .rdp 双向兼容导入 / 导出
  • CLI 支持：linkdesk connect / linkdesk import
