SHA256 校验说明

发布列表会附带 SHA256SUMS.txt。下载后请计算本地文件的 SHA256 并与发布值比对，一致方可使用。

Windows（PowerShell）

Get-FileHash .\EasyRDP-0.1.0-win32-x64-portable.zip -Algorithm SHA256

macOS / Linux

sha256sum EasyRDP-0.1.0-portable.exe
shasum -a 256 EasyRDP-0.1.0-source.tar.gz   # macOS
校验值不一致时请勿运行安装包：可能传输不完整或文件被篡改。请重新下载或到 GitHub Releases 反馈。
