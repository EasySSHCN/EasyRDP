关于各竞品的公允说明

  • mstsc：Windows 自带的远程桌面客户端，系统级 RDP 实现最成熟稳定、零部署成本，是 RDP 场景的事实基准；但它没有内置的连接管理器，高级功能（.rdp 批量管理、编排、CLI）需要用户自行组织。
  • Remmina：老牌开源远程桌面客户端，多协议（RDP/VNC/SSH 等）插件架构与标签页多会话是长期优势，Linux 桌面用户的主力工具之一；其核心在 Linux 生态，Windows/macOS 版本获取渠道与体验相对受限。
  • 向日葵 / ToDesk 类国内远控：面向「跨网络找人帮 / 远控家人电脑」场景，穿透 NAT 与移动端覆盖做得好，对小白用户友好；使用私有远控协议而非标准 RDP，被控端需安装服务组件，商业闭源，部分高级能力与商用场景需付费授权。

EasyRDP 的取舍

EasyRDP 选择做一件克制的事：Windows 上一款免费开源（MIT）、单文件绿色版的 RDP 客户端。它沿用标准 RDP 协议（FreeRDP），不重造私有协议；把工程预算花在连接中心（卡片 / 分组 / Ctrl+K）、.rdp 双向兼容与 JSON 配置即代码、多标签页并行会话、剪贴板文件双向、SAS 菜单与组合键这些日常刚需上。

同时如实说明：macOS / Linux 版本仍在规划中（待 CI 三平台构建接入）；云网关（F4）与管理控制台（F5）列于路线图，v0.4.2 暂未提供。如果你管理的是一批 RDP 主机、希望「拷到 U 盘就能用、连接可进 Git、文件可直接复制粘贴」，EasyRDP 值得一试；如果只是偶尔连一台 Windows 且不想装任何软件，mstsc 仍是可靠的选择。
