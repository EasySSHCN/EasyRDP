核心功能

从个人远程办公到企业批量接入，EasyRDP 用一套开源客户端覆盖完整场景。

🗂

连接中心

卡片式连接管理，一眼看清所有主机；标签页承载多会话并行；Ctrl+K 全局搜索，键盘党极速直达。

📄

配置即代码

连接配置以 JSON Profile 描述，可版本化、可审查；兼容导入 mstsc 的 .rdp 文件，也支持一键导出。

🖥

远程会话

基于 FreeRDP 协议栈，支持 RDP 8+ 压缩、多显示器、剪贴板与驱动器重定向，画面清晰流畅。

🛡

企业网关接入 路线图

规划自有云网关：443 端口 TLS 隧道 + 预认证 + OTP 二次验证，穿透复杂网络环境。

🏢

管理控制台 路线图

规划 SSO/OIDC + MFA、设备重定向策略矩阵、会话水印 / 录制 / 审计，满足企业合规要求。

🔒

安全基线

TLS 1.2+ 加密传输；凭据经 DPAPI / Keychain / libsecret 加密存储；编译期启用 CFG / ASLR 缓解。

三步开始

无需复杂配置，下载、运行、连接，一分钟进入你的远程桌面。

1

下载安装包

前往下载页，选择 Windows zip / macOS dmg / Linux AppImage，并用 SHA256 校验文件完整性。

2

运行 EasyRDP

解压或挂载后直接运行，无需额外安装依赖。首次启动可在"新建连接"中录入主机，或直接导入 .rdp 文件。

3

连接远程主机

双击连接卡片进入会话；Ctrl+K 搜索快速切换，标签页之间自由切换多个远程会话。

100% 开源
