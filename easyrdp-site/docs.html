快速开始 JSON Profile .rdp 导入 CLI 用法

快速开始

1. 从下载页获取对应平台的安装包，并按说明完成 SHA256 校验。
2. Windows 解压 zip 直接运行；macOS 挂载 dmg 拖入应用程序；Linux 对 AppImage 执行 chmod +x 后运行。
3. 启动后点击「新建连接」，填写主机、端口（默认 3389）与认证信息，保存后双击卡片即可进入会话。
4. 使用 Ctrl+K 呼出全局搜索，在多台主机间极速切换。

Windows 需 WebView2 Runtime（Win10/11 通常已内置）；如缺失，运行时会提示自动安装。

JSON Profile

每条连接对应一份 JSON Profile，存放于用户配置目录，可纳入 Git 管理。核心字段如下： 

{
  // 连接名（唯一标识，Ctrl+K 搜索依据）
  "name": "office-win11",
  "host": "192.168.1.100",
  "port": 3389,

  // 认证方式："password" | "nla" | "gateway-otp"（网关路线图）
  "auth": {
    "type": "password",
    "username": "administrator",
    "store": "os-keychain"   // 凭据存入系统凭据库，不落明文
  },

  // 重定向开关
  "redirection": {
    "clipboard": true,
    "drive":   true,
    "printer": false,
    "usb":     false,
    "audio":   true
  },

  // 可选：会话外观
  "session": {
    "resolution": "1920x1080",
    "multiMonitor": false,
    "colorDepth": 32
  },

  // 可选：网关接入（V1 路线图字段，预留）
  "gateway": null
}
Profile 中永远不存储明文密码：auth.store 指向系统凭据库（DPAPI / Keychain / libsecret）的条目引用。

.rdp 导入说明

EasyRDP 兼容 mstsc 生成的标准 .rdp 文件。导入方式有两种：

  • 图形界面：将 .rdp 文件拖入连接中心窗口，或在「新建连接」中选择「导入 .rdp 文件」。
  • 命令行：linkdesk import office.rdp（见下文 CLI）。

支持的字段映射（节选）：

.rdp 字段JSON Profile 字段说明
full address:shost + porthost:port 自动拆分，缺省端口 3389
username:sauth.username用户名；密码不随 .rdp 迁移
desktopwidth / desktopheightsession.resolution初始分辨率
redirectclipboard:iredirection.clipboard剪贴板重定向
drivestoredirect:sredirection.drive驱动器重定向
redirectprinters:iredirection.printer打印机重定向
.rdp 文件中的 password 51:b: 加密块仅在 Windows 本机有效，EasyRDP 导入时不会导入密码，需在连接时重新输入或保存到系统凭据库。

CLI 用法

EasyRDP 附带命令行工具 linkdesk，方便脚本化与 CI 场景：

# 连接：按 Profile 名或 host 连接
linkdesk connect office-win11
linkdesk connect 192.168.1.100 --port 3389 -u administrator

# 导入：将 mstsc .rdp 文件导入为 JSON Profile
linkdesk import office.rdp
linkdesk import ./*.rdp --overwrite

# 其他常用命令
linkdesk list            # 列出全部 Profile
linkdesk export office-win11 -o office-win11.rdp   # 导出 .rdp
linkdesk --version       # 查看版本
CLI 在无桌面环境下仅提供 Profile 管理能力；建立图形会话仍需本地 GUI 环境（依赖 WebView 组件）。
