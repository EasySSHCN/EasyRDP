本版两大主题：① 修复原生远程桌面窗口点击闪现错位/拼贴画面（GDI 背板直绘改造）；② 上线用户反馈全链路——软件端一键反馈（加密上传）、官网后台回复审核、前台「用户之声」精选展示。

Added 新增

  • 用户反馈功能：标题栏「反馈」按钮，支持功能建议/问题反馈/其他分类、联系方式选填、5-2000 字内容（带字数校验）；反馈经 AES-256-GCM 加密信封上传官网（HMAC-SHA256 派生密钥 + 时间窗防重放），随反馈匿名采集系统基础信息（版本/系统/分辨率，不含任何个人身份信息）用于问题定位。
  • 官网「用户之声·反馈精选」：下载页新增板块，展示已回复且公开的用户反馈与官方回复成对内容（仅展示公开条目，最新 10 条，全部转义防 XSS）。
  • 官网统一后台：管理员登录（图形验证码 + 防爆破锁定），反馈管理支持列表筛选 / 回复 / 公开 / 删除 / 手动补录，完整分页；支持修改密码与邮箱绑定自助找回。

Fixed 修复

  • 原生窗口点击闪现错位/拼贴画面（fix36）：新增每窗口 GDI 背板（内存 DC + 兼容位图），帧经 SetDIBitsToDevice 整帧入背板后统一 StretchBlt 呈现，消除 top-down DIB 子矩形源 y 坐标的驱动级歧义；半帧判别收紧为精确等长，异常长度缓冲丢弃等全帧兜底；窗口销毁释放背板防泄漏。

官网 / 基础设施

  • 反馈 API 上线（提交 / 管理 / 公开 TOP10 / 图形验证码），IP 哈希频控（每小时 5 条 + 60 秒间隔）。
  • 每日自动采集用户反馈入需求池 + AI 复审闭环（真实反馈入池公开 / 垃圾下架 / 不纳入开发则关闭回复）。
  • HTML 页面缓存策略优化：版本徽章与页面更新普通刷新（F5）即时生效，无需强制刷新。

v0.1.0（正式版）

2026-11-15 2026-11-15

EasyRDP 首个正式版。绿色免安装：双击即用（Windows 单文件全静态链接，无需任何 DLL）。本版远程桌面核心体验全面落地：原生 FreeRDP 会话窗口、鼠标键盘输入直通、双向剪贴板同步、增量帧管线与残影根修、远端光标形状同步、Win 键与 Ctrl+Alt+Del（SAS）支持。

Added 新增

  • 原生 FreeRDP 会话窗口（Windows）：独立顶层窗口 + 自绘标题栏（最小化/最大化/关闭/拖动），StretchDIBits 全帧直绘，零编码零 IPC 开销。
  • 输入直通：鼠标（移动/左中右键/滚轮/横向滚轮）与键盘全键转发；Win 键经低级键盘钩子拦截转发（远端开始菜单正常使用）。
  • Ctrl+Alt+Del 送达远端：标题栏 SAS 按钮或本地 Ctrl+Alt+End 热键（扩展扫描码序列，服务端合成 SAS）。
  • 剪贴板双向同步（CLIPRDR CF_UNICODETEXT）：本地复制 → 远端粘贴、远端复制 → 本地粘贴，带回环防护。
  • 增量帧管线：脏矩形增量直绘 + EndPaint 全帧（运动期 33ms 节流 ~30FPS + 5s 兜底 + pending 补发），运动期自适应降载。
  • 远端光标形状同步（单色/彩色/32bpp alpha 抗锯齿）；键盘 LED（NumLock/CapsLock）同步。
  • 灾备包机制：源码 + 构建组件 + 恢复文档一键打包，异地设备可完整恢复开发/构建能力。

Fixed 修复

  • 拖拽残影（根修）：全帧快照改读 GDI primary buffer——此前 order 更新（窗口拖动）内容不进合成缓冲导致残影定格。
  • 输入失效根因：窗口过程消息臂缺陷修复（WM_NCCREATE/WM_DESTROY 退化绑定吞掉全部消息）。
  • 关窗后主界面恢复与进程退出；移动/缩放黑块残影；光标黑色方块；ACTIVE 后首包掉线；拖拽 1-2FPS 卡顿——均已修复。

v0.1.0-alpha

初始预览 2026-11-11

EasyRDP 首个公开预览版本（源码形态）。核心远程桌面能力可用，企业网关与管理控制台列入 V1 / V2 路线图。

Added 新增

  • 连接中心：卡片式连接管理、分组与收藏。
  • 标签页多会话：并行运行多个远程桌面会话并快速切换。
  • 全局搜索 Ctrl+K：按主机名 / 备注 / 标签模糊检索连接。
  • JSON Profile：连接配置以 JSON 描述，支持导入 / 导出与版本化管理。
  • .rdp 兼容：支持导入 mstsc 生成的 .rdp 文件，并可导出回 .rdp。
  • 远程会话：基于 FreeRDP 协议栈的基础 RDP 会话，支持剪贴板与驱动器重定向开关。
  • 凭据安全存储：Windows DPAPI / macOS Keychain / Linux libsecret。
  • 跨平台构建：Windows x64 zip、macOS dmg、Linux AppImage 三种产物。
  • CLI 初版：linkdesk connect 与 linkdesk import。

Changed 变更

  • 技术栈确定：Rust + Tauri 2 + FreeRDP 协议栈 + WebView2（Windows）。
  • TLS 策略：强制 TLS 1.2 及以上版本，拒绝弱加密套件。
  • 构建安全：启用 CFG（控制流防护）与 ASLR 编译期缓解。

Fixed 修复

  • 初始发布，无历史问题修复记录。
  • 已知限制：安装包尚未代码签名；多显示器切换在个别驱动下可能出现分辨率抖动（后续版本修复）。
