v0.1.0-alpha

初始发布 2026-11-11

EasyRDP 首个公开预览版本。核心远程桌面能力可用，企业网关与管理控制台列入 V1 / V2 路线图。

Added 新增

  • 连接中心：卡片式连接管理、分组与收藏。
  • 标签页多会话：并行运行多个远程桌面会话并快速切换。
  • 全局搜索 Ctrl+K：按主机名 / 备注 / 标签模糊检索连接。
  • JSON Profile：连接配置以 JSON 描述，支持导入 / 导出与版本化管理。
  • .rdp 兼容：支持导入 mstsc 生成的 .rdp 文件，并可导出回 .rdp。
  • 远程会话：基于 FreeRDP 协议栈的基础 RDP 会话，支持剪贴板与驱动器重定向开关。
  • 凭据安全存储：Windows DPAPI / macOS Keychain / Linux libsecret。
  • 跨平台构建：Windows x64 zip、macOS dmg、Linux AppImage 三种产物。
  • CLI 初版：linkdesk connect 与 linkdesk import。

Changed 变更

  • 技术栈确定：Rust + Tauri 2 + FreeRDP 协议栈 + WebView2（Windows）。
  • TLS 策略：强制 TLS 1.2 及以上版本，拒绝弱加密套件。
  • 构建安全：启用 CFG（控制流防护）与 ASLR 编译期缓解。

Fixed 修复

  • 初始发布，无历史问题修复记录。
  • 已知限制：安装包尚未代码签名；多显示器切换在个别驱动下可能出现分辨率抖动（后续版本修复）。
旧版本归档见 GitHub Releases 页面。企业用户请关注 安全公告 订阅方式。
