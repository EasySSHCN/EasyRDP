Git 同步常见问题：未检测到系统 git

EasyRDP 的 Profile Git 同步（设置 → Git 同步）依赖系统已安装的 Git 命令行工具。若启动同步时提示 「未检测到系统 git」，说明客户端在系统 PATH 中找不到 git.exe。按下面步骤排查即可解决。

① 安装 Git for Windows

打开官网下载页 https://git-scm.com/download/win 下载并安装。安装向导各步骤保持默认即可——默认选项已包含 「将 Git 加入系统 PATH」（Git from the command line and also from 3rd-party software）， 无需改动。

② 已装过 Git？确认 PATH 配置

如果本机之前装过 Git，但 EasyRDP 仍提示未检测到，多半是安装时取消了「加入 PATH」。 请确认目录 C:\Program Files\Git\cmd 已在系统 PATH 中：

  • 按 Win + R 输入 sysdm.cpl → 「高级」→「环境变量」；
  • 在「系统变量」中选中 Path → 「编辑」；
  • 确认列表包含 C:\Program Files\Git\cmd，没有则「新建」加入并确定。
小贴士：绿色版/便携版 Git 也可用，只要保证 git.exe 所在目录（如 ...\PortableGit\cmd）加入系统 PATH。

③ 新开终端验证

修改 PATH 后必须新开一个终端窗口（旧窗口不会重新读取 PATH）。 打开新的 PowerShell 或 CMD，执行：

git --version

输出版本号（如 git version 2.x.x）即配置成功；仍提示 「不是内部或外部命令」则回到第②步检查 PATH。

④ 重启 EasyRDP

完全退出并重新启动 EasyRDP。客户端在启动时探测系统 git，PATH 修复后重启， 「未检测到系统 git」的提示即消失，Git 同步功能恢复可用。 详见 设置面板 · Git 同步。

常见问题

PATH 环境变量到底怎么配？

PATH 是系统查找可执行程序的目录列表。图形界面配法见第②步；也可用管理员 PowerShell 一行完成 （把现有系统 PATH 追加 Git 目录）：

[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","Machine") + ";C:\Program Files\Git\cmd", "Machine")

为什么改完 PATH 必须重启 EasyRDP？

进程的环境变量在启动时从父进程继承一次，之后不再刷新。 EasyRDP 启动时快照了当时的 PATH 并用它探测 git，所以修改 PATH 后只有重新启动 EasyRDP（必要时注销/重启 Explorer）才能拿到新的 PATH。

会和服务器有关系吗？需要服务端配合吗？

不涉及。Git 同步是客户端本地 git 客户端直接与你配置的远端仓库 （GitHub / Gitee / 自建 Git 服务）交互；EasyRDP 服务端仅托管官网与下载分发， 不参与、不经手任何 Profile Git 同步流量。
