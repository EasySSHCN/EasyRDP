导入 .rdp

功能入口

主界面顶部「导入 .rdp」按钮，弹出系统文件选择对话框。

参数说明

    $(System.Collections.Hashtable.params | ForEach-Object { "
  • " } | Out-String).TrimEnd()

典型用法

点击「导入 .rdp」→ 选择一个或多个 .rdp 文件 → 字段自动映射为 EasyRDP JSON Profile 并进入编辑表单 → 校对后「保存连接」。

小贴士：批量迁移：可先用 mstsc 导出多份 .rdp，逐份导入；或直接用「导入JSON」批量导入 EasyRDP 格式。
