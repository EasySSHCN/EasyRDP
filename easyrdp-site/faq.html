常见问题

整理了安装、兼容、网关与安全策略等高频问题。未覆盖的问题请到 GitHub Issues 反馈。

首次运行 Windows 提示"未知发布者 / SmartScreen 拦截"，安全吗？

v0.6.0 安装包尚未购买代码签名证书，因此 Windows SmartScreen 会给出警告（macOS 版本规划中，发布后 Gatekeeper 同理）。 请先按下载页说明完成 SHA256 校验，确认一致后再选择"仍要运行"。 正式版将提供签名安装包与自动更新通道。

如何导入 mstsc 的 .rdp 文件？

两种方式：① 将 .rdp 文件直接拖入连接中心窗口；② 命令行执行 linkdesk import office.rdp。 字段自动映射（full address → host:port，redirectclipboard → 剪贴板开关等），详见文档。 注意：.rdp 中加密的密码块无法跨机迁移，导入后需重新输入并保存到系统凭据库。

EasyRDP 依赖 FreeRDP 吗？我需要单独安装吗？

需要 FreeRDP，但无需单独安装：EasyRDP 将 FreeRDP 协议栈以静态链接 / 随包分发方式内置， 开箱即用。FreeRDP 本身以 Apache-2.0 协议开源，EasyRDP 对其的修改同样公开于源码仓库。

云网关（443 TLS 隧道）如何部署？现在能用吗？

自建网关 0.4.x 起即可部署使用：使用下载页「网关」资产中的 easyrdp-gateway 服务端与 config.example.toml 配置模板， 部署在企业 DMZ 或自有云上，客户端仅出站连接网关 443 端口（TLS 隧道），内网主机 3389 端口零暴露。 官方托管云网关已部署于 easyrdp.cn；自 v0.6.0 起配套云网关用户服务台 gw-admin.html，注册登录后可查看已授权资源并自助签发短期 Token（JWT）。

会话水印 / 录制 / 审计策略如何开启？

这些能力属于管理控制台（V2 路线图）：管理员在控制台以策略矩阵按用户 / 主机 / 时段下发 水印（用户名 + 时间戳）、按需录制与审计日志策略，客户端会话启动时自动拉取并强制执行，终端用户不可关闭。 v0.6.0 阶段可在 JSON Profile 中手动为单条连接启用简单水印（测试用途）。

密码存在哪里？会不会泄露明文？

在 v0.6.0 中，密码仅保存在本机用户配置目录，暂为明文存储，不会上传任何服务器； 后续版本将迁移到操作系统级凭据库（Windows DPAPI、macOS Keychain、Linux libsecret）加密存储， Profile JSON 中仅保留条目引用。更新日志会记录此迁移。 传输层强制 TLS 1.2+，并使用 NLA（网络级身份验证）优先。

连接按钮报错 / 提示"引擎未接入"是什么意思？

v0.6.0 的画面引擎正在接入中：当前版本已实现连接中心（保存 / 编辑 / 删除连接）、 .rdp 导入与 TCP 连通性测试（握手 + 延迟显示），但尚未接入 FreeRDP 图形会话引擎。 因此点击「连接」后会出现"引擎未接入"的提示，这属于预期行为，不代表主机配置有误。 可先用「测试连通」验证主机可达；图形会话能力将在后续版本开放。

密码是如何存储的？安全吗？

在 v0.6.0 中，勾选"记住密码"后凭据仅保存在本机（用户配置目录），不会上传任何服务器， 且当前以明文形式存储在本地文件中——请确保你的用户账户受登录密码保护。 后续版本将切换为操作系统级加密存储：Windows 使用 DPAPI、macOS 使用 Keychain、Linux 使用 libsecret， Profile JSON 中仅保留加密条目引用。安全策略页会同步跟进这一变更。

支持连接哪些版本的 Windows / 远程主机？

支持开启了远程桌面的 Windows 7 SP1 及以上（推荐 Win10/11）、Windows Server 2008 R2 及以上； 同时兼容支持 RDP 协议的第三方实现（如 xrdp、Windows 365 Cloud PC）。macOS / Linux 主机需运行兼容 RDP 的服务端。

连接很卡 / 花屏怎么办？

依次排查：① 检查带宽，建议 ≥ 5 Mbps；② 在连接设置中调低色深（16 位）或分辨率； ③ 确认主机端已启用 RDP 8+ 远程压缩；④ 关闭不使用的驱动器 / 打印机重定向可显著提升首连速度； ⑤ 若仍异常，请到 GitHub Issues 提交 FreeRDP 日志（设置中可开启调试输出）。

Git 同步提示「未检测到系统 git」怎么办？

Git 同步依赖系统安装的 Git 命令行工具。请安装 Git for Windows （默认勾选加入 PATH），并新开终端执行 git --version 验证，然后重启 EasyRDP。 详细排查步骤（含 PATH 配置方法）见 操作手册 · Git 同步排查。
