常见问题

整理了安装、兼容、网关与安全策略等高频问题。未覆盖的问题请到 GitHub Issues 反馈。

首次运行 Windows 提示"未知发布者 / SmartScreen 拦截"，安全吗？

v0.1.0-alpha 安装包尚未购买代码签名证书，因此 Windows SmartScreen 与 macOS Gatekeeper 会给出警告。 请先按下载页说明完成 SHA256 校验，确认一致后再选择"仍要运行"。 正式版将提供签名安装包与自动更新通道。

macOS 如提示"已损坏"，请在终端执行：xattr -cr /Applications/EasyRDP.app。

如何导入 mstsc 的 .rdp 文件？

两种方式：① 将 .rdp 文件直接拖入连接中心窗口；② 命令行执行 linkdesk import office.rdp。 字段自动映射（full address → host:port，redirectclipboard → 剪贴板开关等），详见文档。 注意：.rdp 中加密的密码块无法跨机迁移，导入后需重新输入并保存到系统凭据库。

EasyRDP 依赖 FreeRDP 吗？我需要单独安装吗？

需要 FreeRDP，但无需单独安装：EasyRDP 将 FreeRDP 协议栈以静态链接 / 随包分发方式内置， 开箱即用。FreeRDP 本身以 Apache-2.0 协议开源，EasyRDP 对其的修改同样公开于源码仓库。

云网关（443 TLS 隧道）如何部署？现在能用吗？

网关属于 V1 路线图，v0.1.0-alpha 暂不包含。规划形态：网关以独立服务部署在企业 DMZ 或自有云上， 客户端仅出站连接网关 443 端口（TLS 隧道复用 HTTPS 通道），接入需预认证 + OTP 二次验证， 内网主机 3389 端口零暴露。届时将提供 Helm / Docker 部署方案与配置文档。

会话水印 / 录制 / 审计策略如何开启？

这些能力属于管理控制台（V2 路线图）：管理员在控制台以策略矩阵按用户 / 主机 / 时段下发 水印（用户名 + 时间戳）、按需录制与审计日志策略，客户端会话启动时自动拉取并强制执行，终端用户不可关闭。 v0.1.0-alpha 阶段可在 JSON Profile 中手动为单条连接启用简单水印（测试用途）。

密码存在哪里？会不会泄露明文？

勾选"记住凭据"后，密码存入操作系统级凭据库：Windows 使用 DPAPI、macOS 使用 Keychain、Linux 使用 libsecret， Profile JSON 中仅保留条目引用，不落明文。传输层强制 TLS 1.2+，并使用 NLA（网络级身份验证）优先。

支持连接哪些版本的 Windows / 远程主机？

支持开启了远程桌面的 Windows 7 SP1 及以上（推荐 Win10/11）、Windows Server 2008 R2 及以上； 同时兼容支持 RDP 协议的第三方实现（如 xrdp、Windows 365 Cloud PC）。macOS / Linux 主机需运行兼容 RDP 的服务端。

连接很卡 / 花屏怎么办？

依次排查：① 检查带宽，建议 ≥ 5 Mbps；② 在连接设置中调低色深（16 位）或分辨率； ③ 确认主机端已启用 RDP 8+ 远程压缩；④ 关闭不使用的驱动器 / 打印机重定向可显著提升首连速度； ⑤ 若仍异常，请到 GitHub Issues 提交 FreeRDP 日志（设置中可开启调试输出）。
