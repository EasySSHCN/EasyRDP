参与贡献

EasyRDP 是社区驱动的开源项目，欢迎任何形式的贡献：代码、文档、翻译、测试与Issue 反馈。

🐛

1 · 提交 Issue

发现 Bug 或有功能建议，请先在 GitHub Issues 搜索是否已有重复条目， 再按模板新建。Bug 报告请附：平台与版本（linkdesk --version）、复现步骤、期望与实际行为、调试日志。

🛠

2 · 搭建开发环境

git clone https://github.com/EasySSHCN/EasyRDP.git
cd easyrdp

# 依赖：Rust 稳定工具链（rustup）、Node.js 18+（前端构建）、各平台 WebView 运行时
rustup default stable
pnpm install

# 开发模式运行
cargo tauri dev

# 构建发布包
cargo tauri build
🔀

3 · 提交 Pull Request

  • 从 main 分支切出特性分支：git checkout -b feat/my-feature。
  • 提交信息遵循 Conventional Commits（feat: / fix: / docs: 等）。
  • 确保 cargo fmt --check、cargo clippy 与现有测试通过；新增功能请补充测试。
  • 涉及 UI 的改动请附截图；涉及协议 / 安全的改动请在描述中说明设计考量。
  • 提交前请同步更新 更新日志（Unreleased 段）。
🌍

4 · 文档 / 翻译 / 测试

文档位于仓库 site/ 目录（即本站点），修改后直接提 PR； 翻译贡献请查看 locales/ 目录说明；多平台真机测试反馈请在新版本发布公告下回帖。

安全漏洞请勿通过公开 Issue 提交，请参阅安全策略通过私密渠道报告。 参与 EasyRDP 即表示你同意项目行为准则：尊重他人、聚焦技术、保持开放。 所有贡献在 MIT 协议下授权。
