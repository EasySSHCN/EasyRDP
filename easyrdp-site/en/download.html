SHA256 Verification

The SHA256 values in the cards above come from SHA256SUMS.txt (updated automatically with every release). After downloading, compute the SHA256 of your local file and compare it with the card value; only use the file when they match.

Windows (PowerShell)

Get-FileHash .\EasyRDP-0.4.2-win32-x64-portable.zip -Algorithm SHA256

macOS / Linux

sha256sum EasyRDP-0.4.2-portable.exe
shasum -a 256 EasyRDP-src-0.4.2.tar.gz   # macOS
If the checksum does not match, do not run the installer: the transfer may be incomplete or the file may have been tampered with. Download again or report it on GitHub Releases.
