Contributing

EasyRDP is a community-driven open-source project, and contributions of any kind are welcome: code, documentation, translations, testing, and issue reports.

🐛

1 · File an Issue

If you find a bug or have a feature suggestion, first search GitHub Issues for duplicates, then open a new one using the template. Bug reports should include: platform and version (linkdesk --version), reproduction steps, expected vs. actual behavior, and debug logs.

🛠

2 · Set Up a Development Environment

git clone https://github.com/EasySSHCN/EasyRDP.git
cd easyrdp

# Requirements: Rust stable toolchain (rustup), Node.js 18+ (frontend build), platform WebView runtimes
rustup default stable
pnpm install

# Run in development mode
cargo tauri dev

# Build a release package
cargo tauri build
🔀

3 · Submit a Pull Request

  • Branch off main for your feature: git checkout -b feat/my-feature.
  • Follow Conventional Commits for commit messages (feat: / fix: / docs:, etc.).
  • Make sure cargo fmt --check, cargo clippy, and the existing tests pass; add tests for new features.
  • Attach screenshots for UI changes; explain the design considerations in the description for protocol / security changes.
  • Before submitting, update the Changelog (Unreleased section) accordingly.
🌍

4 · Documentation / Translation / Testing

The documentation lives in the repository's site/ directory (this very site); just open a PR after your changes. For translation contributions, see the notes in the locales/ directory; to report results of real-device testing across platforms, reply under the new release announcement.

Please do not report security vulnerabilities through public issues; see the Security Policy to report them through a private channel. By participating in EasyRDP you agree to the project's code of conduct: respect others, stay technical, keep an open mind. All contributions are licensed under the MIT license.
