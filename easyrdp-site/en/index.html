EasyRDP

Built on the Rust + Tauri 2 + FreeRDP stack, 100% open source (MIT license). A Windows build is available now (macOS / Linux planned). Portable, no installation required: download, extract and run — no registry entries, no leftover files. Card-based connection management, tabbed multi-session support, and configuration as code — remote desktop that is both easy to use and easy to control.

Core Features

From personal remote work to enterprise-wide rollout, EasyRDP covers the full range of scenarios with a single open source client.

🗂

Connection Center

Card-based connection management shows every host at a glance; tabs carry multiple parallel sessions; Ctrl+K global search gets keyboard users there in seconds.

📄

Configuration as Code

Connection settings are described in JSON profiles — versionable and reviewable. Import mstsc .rdp files directly, or export your connections back out in one click.

🖥

Remote Sessions

Powered by the FreeRDP stack: RDP 8+ compression, multi-monitor, clipboard and drive redirection. v0.3.4 adds a pre-connection TCP connectivity check (one-click verification of host reachability and port response); the rendering engine is on its way.

🛡

Enterprise Gateway Access Roadmap

A planned self-hosted cloud gateway: TLS tunnel over port 443 + pre-authentication + OTP second-factor verification, cutting through even the most complex network environments.

🏢

Admin Console Roadmap

Planned SSO/OIDC + MFA, a device redirection policy matrix, and session watermarking / recording / audit logging to meet enterprise compliance requirements.

🔒

Security Baseline

TLS 1.2+ encrypted transport; credentials stored encrypted via DPAPI / Keychain / libsecret; CFG / ASLR mitigations enabled at build time.

Get Started in Three Steps

No complex configuration needed — download, run, connect, and you are inside your remote desktop within a minute.

1

Download the Package

Go to the download page, grab the Windows build, and verify file integrity with SHA256 (macOS / Linux builds are planned).

2

Run EasyRDP

Extract or mount and run directly — no extra dependencies required. On first launch, add your host under "New Connection", or simply import a .rdp file.

3

Connect to a Remote Host

Double-click a connection card to start a session; use Ctrl+K search to switch instantly, and move freely between multiple remote sessions across tabs.

100% Open Source

EasyRDP is open sourced under the MIT license, with a stack of Rust + Tauri 2 + FreeRDP + WebView2 — no closed-source components, no telemetry backdoors. Issues and PRs are welcome on GitHub / Gitee. Let's build a more open, enterprise-grade remote desktop experience together.
