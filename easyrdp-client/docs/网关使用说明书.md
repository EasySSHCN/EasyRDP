# EasyRDP 网关使用说明书（软件端 · v0.3.13）

> 适用版本：v0.3.7 及以上（本文以 v0.3.13 界面为准）
> 适用对象：使用企业网关接入远程桌面的最终用户

---

## 1. 什么是网关？我需要用它吗？

**网关**是部署在公司云端的一台中转服务器。当你要连接的远程电脑位于公司内网、或公司要求统一经过安全网关接入时，就需要在连接里配置网关。

- 普通家庭/个人直连场景：**不需要**配置网关，保持「网关（可选）」折叠区收起即可
- 公司统一接入场景：向公司管理员索取 **4 项信息**（见下表），然后按第 2 节配置

## 2. 配置前需要向管理员索取的信息

| # | 信息 | 说明 | 示例 |
|---|------|------|------|
| 1 | 网关地址 | 网关服务器域名或 IP（含端口更好） | `gw.company.com:8443` |
| 2 | 认证方式 | Token（个人接入令牌）或 用户名+密码 | — |
| 3 | 认证凭据 | Token 字符串，或网关账号密码；如启用了二次验证还需要 OTP 动态码 | — |
| 4 | 资源 ID | 你要连的那台远程主机在网关上注册的名字 | `rdp-office-01` |

> 💡 拿到网关地址后，**直接把完整地址粘贴进输入框即可**——支持 `https://gw:8443`、`wss://…` 等格式，软件会自动拆分域名、端口并勾选 TLS，无需手动填写。

## 3. 配置步骤（新建连接）

1. 主界面点击 **「+ 新建连接」**
2. 正常填写「计算机 / 端口 / 用户名 / 密码」（这是**远程电脑**的信息，与网关无关）
3. 展开 **「网关（可选）」** 折叠区，按下方字段说明填写：

| 字段 | 填写说明 |
|------|----------|
| **网关地址** | 管理员给的域名或 IP；支持直接粘贴 `https://gw:8443` 完整地址（自动拆分） |
| **端口** | 一般 443；管理员另有说明则按说明填 |
| **TLS** | 网关走加密（wss/https）时勾选，**保持勾选**除非管理员明确说不用 |
| **认证方式** | 二选一：`Token`（粘贴管理员发的令牌）/ `用户名密码`（填网关账号密码） |
| **Token / 用户名 / 密码** | 按所选认证方式填写；密码保存后以 Windows DPAPI 加密存储在本机，不上传 |
| **资源 ID** | 目标主机在网关上的注册名（如 `rdp-office-01`），填错会连接失败 |
| **允许自签证书** | 仅当管理员说明网关使用自签证书时勾选（默认关闭，勿随意开启） |

4. （可选）点击 **「+ 添加备用网关」** 添加备用网关条目——主网关连不上时自动切换备用
5. 点击 **「检测网关连通性」**：每个网关会显示 🟢 可达（含延迟）或 🔴 不可达（含原因），确认 🟢 后再连接
6. 点击 **「保存连接」**。之后双击连接即可经网关连入远程桌面

## 4. 连接过程中的认证交互

| 情况 | 软件行为 | 你要做的 |
|------|----------|----------|
| Token 有效 | 直接进入远程画面 | — |
| 网关要求 **OTP 二次验证** | 弹出输入框提示「网关要求 OTP 二次认证」 | 打开手机验证器（Authenticator 等），输入当前 6 位动态码 |
| OTP 码错误 | 再次弹框要求重输 | 重新输入（注意动态码每 30 秒刷新） |
| 策略被拒绝（403） | 提示 `policy_denied` 相关信息 | 你的账号没有该资源的访问权限，联系管理员开通 |
| Token 过期 | 提示认证失败 | 重新保存连接（更新 Token）或联系管理员重新签发 |

> 🔐 **安全说明**：网关凭据（Token/密码）在本机以 Windows DPAPI 加密存储，不上传任何服务器； OTP 动态码仅本次连接使用，不落盘。

## 5. 多网关与备用切换

- 可添加多个网关条目：连接时**按顺序尝试**（主 → 备 1 → 备 2 …），单条尝试超时 5 秒自动切下一个
- 「检测网关连通性」会并发检测所有条目并显示延迟
- 某个网关故障时，**下一次连接**会自动优先使用上次成功的节点，并按序轮转其余节点
- 说明：若网关在会话中途断开，当前远程画面会断开（RDP 协议限制），重新双击连接即可——软件会自动优先使用刚才可用的网关

## 6. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 提示连接超时 (5s) | 网关地址/端口错误，或网关宕机 | 点「检测网关连通性」逐项排查；确认网络可达 |
| 提示 `otp_required` | 网关开启了二次验证 | 输入动态码重试 |
| 提示 401 / Token 无效 | Token 过期或填错 | 向管理员重新索取；编辑连接更新 Token |
| 提示 403 / 无权限 | 策略矩阵未放行你的账号或资源 | 联系管理员在网关策略中放行 |
| 自签证书连接失败 | 网关用自签证书而你未勾选豁免 | 确认是公司内部网关后勾选「允许自签证书」 |
| 资源不存在 | 资源 ID 填错，或目标主机未在网关注册 | 核对资源 ID；联系管理员注册目标主机 |
| 连上了但很卡 | 网关带宽/线路质量 | 换备用网关或联系管理员 |

## 7. 升级与网关功能

- 软件支持在线升级（发现新版本时标题栏下方会出现**常驻横幅**，点「立即升级」直接在横幅内完成下载安装）
- 网关相关功能自 **v0.3.7** 引入，**v0.3.11** 增加 wss/OTP/多网关，**v0.3.13** 增加备用网关与健康探测——请保持升级到最新版以获得完整体验

## 8. 隐私与安全承诺

- 网关凭据仅保存在**本机**，Windows DPAPI 加密，不随 Profile 导出、不上传服务器
- 连接经网关时，网关侧仅记录匿名化的连接审计信息（时间/IP/资源/结果），不记录键盘输入与画面内容
- 模板导出功能会**强制剥离**所有网关凭据，可安全分享给同事
