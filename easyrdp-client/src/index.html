新建连接

网关（可选）（经云网关中转连接，普通直连无需展开）

提示：官方云网关填 easyrdp.cn（端口 443、TLS 选「启用」）。把 https://easyrdp.cn 这样的完整地址直接粘贴进「网关地址」，域名 / 端口 / TLS 会自动识别。认证方式按管理员发放的凭证选择：「Token（JWT）」直填网关签发的令牌；「用户名密码」由客户端向网关换取短期票据，密码仅存本机。「资源 ID」是网关后台注册的资源名（如 rdp-win01），留空则按本连接的服务器地址直连（受网关私网白名单约束）。

高级 / 端口敲门（服务器开了 knockd/fwknop 时才需配置，普通直连无需展开）

SPA 包由 fwknop 官方 libfko 库构造（Rijndael-256 加密 + HMAC-SHA256），与原生 fwknopd 逐字节互通。密钥为 fwknop 原生裸密钥语义（与 fwknop --key-gen / access.conf KEY / HMAC_KEY 兼容）：服务器 access.conf 填什么明文密钥，这里就填同一明文。注意：2026-11-22 改版前的旧自研格式密钥已失效，需与服务器端同步重新生成。

    Git 同步

    把连接 / 分组 / 模板数据通过独立 git 仓库在多台机器间同步。

    已保存（本机加密）
    安全说明：同步副本中的密码 / Token 等凭据密文（DPAPI，绑定本机用户）会被替换为「dpapi:<不可迁移>」占位符，不会进入 git 仓库。从远端恢复后，凭据字段为空，需要在本机重新填写。
    需要系统已安装 git 命令并加入 PATH。

    组合键

    远程窗口标题栏 SAS 菜单的「全局」自定义组合键（对所有会话生效）。

    格式：用 + 连接，支持 Win / Ctrl / Alt / Shift / 单个字母数字 / F1-F12 / Esc / Tab / Enter / Del / 方向键等。添加后出现在远程窗口 SAS 菜单底部。
